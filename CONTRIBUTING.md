# Contributing

Contributions are welcome through pull requests or the `Add a paper` issue form.

## Required metadata

- Year
- Venue
- Exact title
- Stable paper URL (prefer DOI/publisher/arXiv/OpenReview/ACL Anthology)
- Category
- Publication status (`published`, `conference`, `workshop`, `preprint`, or `white-paper`)
- Official code URL when available

## Rules

1. Do not label a preprint as an IEEE Transactions article without an official DOI/early-access page.
2. Do not add a code link based only on name similarity; the paper or repository must establish the relationship.
3. Avoid duplicate preprint and journal entries unless they provide distinct artifacts and the relationship is explained.
4. Keep titles verbatim except for capitalization normalization.
5. Run `python scripts/validate_catalog.py` before opening a pull request.
