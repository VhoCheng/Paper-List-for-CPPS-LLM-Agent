## 5. 核验中发现的易错点

- **GraLan 的 DOI 错链**：arXiv 记录写成 `10.1007/978-3-032-09527-5_3`，对应的是另一篇论文。逐项核对 Springer 目录后，正确 DOI 为 [`10.1007/978-3-032-09527-5_33`](https://link.springer.com/chapter/10.1007/978-3-032-09527-5_33)。该文实际为 ISWC 2025，2026 年才上传 arXiv，因此按 2025 历史补录。
- **PowerAtlas 版本变化**：采用 2026-10-15 的 v2 题名和方法说明；旧标题和旧摘要不能直接代表最新版。
- **GNN-RAG 与 GraphWiz 正式题名**：以 ACL / ACM 正式记录为准，保留 arXiv 作为开放版本链接。
- **LLMs+Graphs 的会议年份异常**：arXiv 注释含 “PAKDD 2066”；仅据此不能认定正式发表，保留为 2026 预印本。
- **会议投稿或作者自述录用**：未找到独立正式出版记录时，仍按所链接的预印本列出，并在核验数据中备注。
- **原有 PowerChain 两个版本**：P016 与 P029 是正式版与早期预印本关联，保留原 ID，不作为两项独立研究证据。因此所有统计使用“条记录”。
- **GraphInfer-Bench 代码**：论文给出的 GitHub 地址本次返回 404，未核验到可访问仓库，故主清单保留论文/PDF、暂不列为可用代码；原地址留在核验数据中。其他新增代码/资源链接涉及的 16 个不同仓库均通过 GitHub 存在性检查，但未运行代码。
- **代码链接**：仅收录论文、作者页面或对应官方仓库明确关联的链接；留空表示本次未核实到，不表示作者一定未开源。PDF 优先给出合法开放预印本，不承诺全部为出版社最终版。

## 6. 如何上传

解压完整更新包，将 `Paper-List-for-CPPS-LLM-Agent-updated` 目录**里面的文件和目录**上传到现有 GitHub 仓库根目录，替换同名文件。不要把外层目录再作为一个子文件夹上传。原有 LICENSE、贡献说明和数据字段已保留；CSV/JSON 与 README 同步生成。

如果只想先审阅新增内容，阅读本文件和 [Graph + LLM 专章](GRAPH_LLM.md)。可在本地运行 `python3 scripts/validate_catalog.py`，再运行 `python3 scripts/validate_update.py` 检查数据、章节数量与新增核验记录的一致性。

尚未执行任何 GitHub 上传或提交。
